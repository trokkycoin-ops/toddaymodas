TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────────

❌ "Plugin não tem arquivo principal"
   → ZIP está corrompido
   → Solução: Use o arquivo: todday-modas-brecho-prod.zip
   → Se ainda não funcionar, reinstale do arquivo novo

❌ Layout não mudou
   → Cache do navegador
   → Solução 1: Ctrl+Shift+Delete → Limpar tudo → F5
   → Solução 2: Desativar/Reativar o plugin
   → Solução 3: Limpar cache do WordPress (se houver plugin de cache)

❌ Erro ao ativar
   → Versão PHP incompatível
   → Requerimento: PHP 8.1+
   → Solução: Contate provedor de hospedagem
