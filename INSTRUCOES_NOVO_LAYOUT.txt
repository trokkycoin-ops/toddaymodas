PARA VER AS MUDANÇAS NO SEU SITE:
═════════════════════════════════════════════════════════════════

1. LIMPAR CACHE DO NAVEGADOR:
   - Pressione: Ctrl + Shift + Delete (Windows) ou Cmd + Shift + Delete (Mac)
   - Selecione "Arquivos em cache" e "Cookies"
   - Clique em "Limpar dados"

2. DESATIVAR E REATIVAR O PLUGIN:
   a) No WordPress Admin → Plugins
   b) Procure por "Todday Modas Brechó"
   c) Clique em "Desativar"
   d) Aguarde 5 segundos
   e) Clique em "Ativar"

3. LIMPAR CACHE DO WORDPRESS (se usar plugin de cache):
   - WP Super Cache: Admin → WP Super Cache → Deletar Cache
   - W3 Total Cache: Admin → Performance → Empty All Caches
   - Elementor: Admin → Elementor → Tools → Regenerate CSS

4. ACESSAR A PÁGINA DA LOJA:
   - Vá para a página que contém [todday_loja] ou [tm_home]
   - Atualize a página (F5 ou Ctrl+R)
